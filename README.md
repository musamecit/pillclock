# PillClock

Website for **PillClock**, an offline medication reminder for iPhone.

| Page | URL |
|---|---|
| Marketing | https://musamecit.github.io/pillclock/ |
| Privacy Policy | https://musamecit.github.io/pillclock/privacy.html |
| Support | https://musamecit.github.io/pillclock/support.html |

PillClock is a reminder tool. It is not a medical device and does not give
medical advice. It never recommends starting, stopping or changing a
medication — those decisions belong to a qualified medical doctor.

The app collects no data and has no internet permission.
